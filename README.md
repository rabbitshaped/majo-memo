# Majo Memo 🌙

This is a whimsical note-taking application inspired by Angela Yu's React course and reimagined with a cozy witchy stationery aesthetic. 
Majo Memo combines simple note-taking with magical-themed memo pads, to-do lists, reminders, and idea cards.

## Features

### Multiple note types

* Memo Pads
* To-Do Lists
* Reminder Cards
* Idea Notes

### Editing experience

* Click any note to edit it.
* Press **Enter** or click outside the note to save changes.
* Notes automatically switch between editing and reading modes.

### Visual personality

* Randomized washi tape for memo notes.
* Handwritten-style typography.
* Different backgrounds for different note types.
* Cute witch-inspired UI with soft purple tones.

## Tech Stack

* React
* JavaScript
* CSS
* Lucide React Icons

## Known Issues

* Notes overflow past the footer after layout is full.
* Search bar UI exists but searching is not yet implemented.
* Responsiveness is not yet added, as it is, this app is presently desktop-only.
